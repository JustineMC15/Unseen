# Audio Asset Attributions

This file records the audio sources currently in the horror-game audio plan. Keep it with the project and update it if a source is replaced. Only credit assets that are actually included in the shipped game.

## Required attribution

The OpenGameArt page for **Dark Ambience Loop** gives a specific credit instruction. Include this exact line in the game's credits screen or video credits:

> Dark Ambience Loop by Iwan Gabovitch qubodup.net

Source: https://opengameart.org/content/dark-ambience-loop
